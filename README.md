# CreditWise Loan Approval System

## Overview
This project is a Machine Learning-based Loan Approval Prediction System that predicts whether a loan application will be approved or not based on user inputs.

## Features
- Data preprocessing and cleaning
- Feature encoding (One-Hot Encoding)
- Feature scaling (StandardScaler)
- Machine Learning models (Logistic Regression, KNN, Naive Bayes)
- Model evaluation using accuracy metrics
- Streamlit-based deployment (app.py)

## Files Included
- model.pkl → Trained ML model
- scaler.pkl → Feature scaling object
- ohe.pkl → Categorical encoding object
- app.py → Deployment application
- loan_approval_data.csv → Dataset
- loan_model.ipynb → Model training notebook

## Tech Stack
Python, Pandas, Scikit-learn, Streamlit, Jupyter Notebook

## Goal
To automate loan approval prediction using machine learning techniques.
